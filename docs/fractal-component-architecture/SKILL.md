name: fractal-component-architecture
description: "Apply Fractal Component Architecture (FCA): structure any software project as a tree of components, where a component's children are exactly what sits one directory level beneath it. Every component is born as a folder with an entry point (a class, or the language's closest idiom) that is either a pure container or an active component, never a bare file that later becomes a folder. Covers repo root vs. software root, strong typing, and per-language guides in languages/ (Python, JS/TS, Java, C#, Go, Rust, C++, C, Ruby). Use when designing or reviewing project architecture, deciding where a module/class/file lives, whether a folder needs its own entry point, what belongs at the repo root vs. the software folder, or wiring dependencies in a composition root."
