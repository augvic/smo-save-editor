# 🏠 Overview

The first tab, for the numbers of the player. Needs a save slot (`File1.bin`).

## 👤 Player
- **Coins**: the coins Mario is carrying. If you type more than the lifetime counter, **Total coins** is raised to match.
- **Total coins**: the lifetime coin counter.
- **Play time**: hours and minutes.
- **Jaxi / Jango count**.

## 👕 Equipment
The **Cap** and **Outfit** Mario wears, plus **Random cap** and **Random outfit**. Only items you own can be picked. To own more,
use the shops in the [Kingdoms](kingdoms.md) tab.

## 📍 Location
Where the game puts Mario when it loads this save.
- **Kingdom**: picking one moves Mario to that kingdom's overworld. If it is locked, it is unlocked first, with the kingdoms before it. It also sets the previous kingdom, the first-visit state and the Main scenario the way the game does when you travel.
- **Stage**: the stage that loads. The home stage of a kingdom is its main overworld; the list also has the sub-areas.
- **Start point ID**: which entrance or checkpoint Mario appears at. Leave it empty for the stage's default.

## 📊 Statistics
Jumps, cap throws, jump rope and volleyball records, race losses.

## 🚩 Flags
Mario has his cap (Cappy), Assist mode, riding the motorcycle, the opening cutscene played, achievements unlocked.
