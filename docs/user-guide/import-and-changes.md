# 📥 Import and 🕘 Changes

## 📥 Import
Copy parts of another save into the open one, or just see how two saves differ.

1. Press **Choose a save…** and pick another save slot. It is only read; it is not opened for editing.
2. Each section shows how many values differ: moons, purple coins, progress, unlocked kingdoms, wardrobe, captures, music, checkpoints, side areas, achievements and races. For sections that depend on kingdoms you can tick one kingdom at a time.
3. Tick what to copy and press **Copy ticked parts into this save**. Nothing changes until then.

The copy is an ordinary edit, so **Undo** takes it back. Importing a section can leave related numbers out of step, so look at [Checks](checks-and-report.md) afterwards.

## 🕘 Changes
Every value that differs now from the file as it was opened (or last saved), in the order you first touched it, with the old value and the new one. **Revert** puts one value back. Saving starts a fresh list.

Use it before saving to be sure that you changed only what you meant to.
