# 📖 SMO Save Editor: user guide

How to use the editor, one page per tab. Start with [Getting started](getting-started.md).

| Guide | What it covers |
|---|---|
| [🚀 Getting started](getting-started.md) | Opening and saving files, Undo and Redo, how the editor protects your save |
| [🏠 Overview](overview.md) | Coins, play time, equipment, where Mario is, statistics, flags |
| [🗺️ Kingdoms](kingdoms.md) | Unlocking, scenarios, Power Moons, purple coins, shops, checkpoints, cutscenes |
| [🏆 Achievements](achievements.md) | Goals, captures, the jukebox, race records |
| [🛡️ Checks and 📋 Report](checks-and-report.md) | Finding what does not agree in the save, and what is still missing |
| [📖 Story flags](story-flags.md) | Bosses, cutscenes of the whole game, shop markers |
| [📥 Import and 🕘 Changes](import-and-changes.md) | Copying parts of another save, and reviewing every edit |
| [🔧 Raw data and ⚙️ Game settings](raw-data-and-settings.md) | Every value in the file, and `Common.bin` |

> ⚠️ Always keep a copy of your original saves. The editor never writes over them, but the game may reject a save that was edited wrongly.
