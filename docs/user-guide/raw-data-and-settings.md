# 🔧 Raw data and ⚙️ Game settings

## 🔧 Raw data
Every value in the open files, as a tree you can expand, for anything the other tabs do not cover. Numbers keep their original type and range; a value of the wrong kind is rejected.
This is the place for the DLC list in `Common.bin` too.

> ⚠️ Raw edits do not keep related values in step. Prefer the other tabs when one exists, and look at [Checks](checks-and-report.md) afterwards.

## ⚙️ Game settings
The settings stored in `Common.bin`, shared by all save slots: camera and vibration options, among others. The tab is greyed out until `Common.bin` is open.
Open it together with a save slot with **Open saves…**.
