# 🏆 Achievements

Goals and records. Needs a save slot.

- **Captures**: everything Mario can capture, from the game's own list. Mark the ones you have.
- **Music**: the jukebox tracks. A track the save has not listed yet is added when you mark it.
- **Races**: whether each race was won, and the best times as `m:ss.cc` (empty for none).
- **Achievement lists**, by category (Story, Power Moon challenges, Mini-games, Souvenirs, Captures, Costumes, Other): the game's own achievements, with their names. Marking one only marks the flag, so keep it in line with what you actually collected.

Each list has a search box and **Collect shown** / **Clear shown**, which change everything the filter currently shows.
The [Checks](checks-and-report.md) tab warns when a "Gather" Power Moon achievement is marked while you are below its goal.
